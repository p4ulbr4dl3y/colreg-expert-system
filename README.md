# Экспертная система расхождения судов

Система помогает морскому персоналу принимать решения при расхождении с другими судами в соответствии с Международными правилами предупреждения столкновений судов в море.

## Что делает система

Система анализирует навигационную обстановку и выдаёт рекомендации:

- определяет тип столкновной ситуации: встречные курсы, пересечение, обгон;
- устанавливает роль судна: уступает дорогу, имеет преимущество, оба маневрируют;
- рекомендует действие: сохранять курс и скорость, изменить курс вправо или влево, снизить ход;
- рассчитывает безопасный курс с учётом опасных секторов;
- проверяет физическую возможность маневра с учётом радиуса циркуляции;
- подбирает необходимые звуковые сигналы.

## Какие правила учитываются

Система учитывает следующие правила МППСС-72:

- правило 12 - расхождение парусных судов;
- правило 13 - обгон;
- правило 14 - встречные курсы;
- правило 15 - пересечение курсов;
- правило 17 - действия судна, имеющего преимущество;
- правило 18 - взаимные обязанности судов разных типов;
- правило 19 - действия при ограниченной видимости;
- правила 34 и 35 - звуковые сигналы.

## Типы судов

Система учитывает приоритеты разных типов судов согласно правилу 18:

- судно, лишённое возможности управляться;
- судно, ограниченное в возможности маневрировать;
- судно, стеснённое своей осадкой;
- судно, занятое ловом рыбы;
- парусное судно;
- судно с механическим двигателем.

## Условия обстановки

Система работает в следующих условиях:

- хорошая видимость;
- ограниченная видимость (туман, дождь и т.п.);
- узкий фарватер;
- система разделения движения.

## Запуск демонстрации

Для запуска демонстрации потребуется установленный пакетный менеджер uv и Python версии 3.12 или выше.

Порядок запуска:

- установите зависимости проекта командой `uv sync`;
- запустите веб-сервер командой `uv run python scripts/demo_web.py`;
- откройте в браузере адрес `http://127.0.0.1:8080` (порт может отличаться, точный адрес будет указан в выводе команды).

После запуска в левой части экрана отобразится список сценариев. Выберите любой из них, чтобы увидеть навигационную обстановку, рекомендованное действие и пошаговое объяснение.

## Демонстрационный интерфейс

Система оснащена веб-интерфейсом с набором готовых сценариев. Каждый сценарий демонстрирует конкретное правило МППСС-72 и содержит:

- описание ситуации;
- визуализацию навигационной обстановки на радаре;
- рекомендованное действие и курс;
- пошаговое объяснение логики вывода;
- перечень применённых правил.

### Представленные сценарии

Веб-интерфейс включает следующие сценарии:

- встречные курсы - два судна идут нос к носу;
- цель справа - пересечение курсов, цель по правому борту;
- обгон - догон более медленного судна;
- парусное судно - встреча механического и парусного судов;
- ограниченная видимость - пересечение курсов в условиях плохой видимости;
- две цели - одновременное расхождение с двумя судами;
- маневр не успевает - ситуация, когда поворот физически невозможно завершить вовремя.

## Пояснения к результатам

Для каждого судна-цели система сообщает:

- тип ситуации: встречные курсы, пересечение слева или справа, обгон;
- роль нашего судна: уступает дорогу, имеет преимущество;
- кратчайшее расстояние сближения в морских милях;
- время до момента наибольшего сближения в минутах.

Итоговое решение содержит:

- рекомендованный курс;
- опасные сектора, которых следует избегать;
- предупреждение, если маневр невозможно завершить до момента сближения;
- необходимые звуковые сигналы.
